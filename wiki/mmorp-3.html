MMORP 3

The unfinished Scratch sequel that introduced mouse movement.

On this page

  1. Overview
  2. Movement and settings
  3. Versions
  4. Gallery

Overview

MMORP 3 was the final entry in the original Scratch trilogy and remained unfinished. It introduced a more advanced menu, new levels, skins, and a revised movement system.

Movement and settings

Rather than moving directly with the arrow keys, MMORP follows the mouse with a smoothing effect. This change also removed the original game’s screen wrapping.

Video settings include pixelation, a fisheye-like warp, and color changes. Some of those effects originated as experimental settings in the first game’s Evtest mode.

Versions

The project included a gameplay test and a “deduxe” version associated with Wii U and Joel’s website. The Wii U version was not publicly released, according to the project notes.
